## Exact visual position

```ts
desired = status === "delivered" ? 1 : clamp(worldClockMinutes / Math.max(projectedArrivalMinute, 1), 0, .97);
visual = status === "delivered" ? 1 : status === "held" ? previousVisual : Math.max(previousVisual, desired);
originSeparationWeight = clamp(1 - progress / 0.08, 0, 1);
routePoint = from + (to-from) * progress;
displayPoint = routePoint + originOffset * originSeparationWeight;
// alpha offset=(0,-12), delta=(0,+12); beta/gamma=(0,0)
```

State persists per run via refs. Backtracking is prevented even if ETA increases. Held freezes at previous visual position; delivered jumps to 1. CSS transform transition is 850ms cubic-bezier(.22,.75,.2,1). Origin separation vanishes at progress .08. Visual marker position is NOT a simulated traveled-distance state and never enters mission/telemetry/scoring. All 128 traces had zero exposed held states because mission status recomputation resets the transient hold flag.

## Status styling

- moving: dashed route flow, cyan truck.
- held: route animation disabled, gray truck and Ⅱ marker; supported but not observed at any exposed snapshot.
- compromised: orange truck/ring and pulsing warning; source condition integrity<55.
- delivered: route animation disabled, completion ring/check; progress1.
- fallbackNav→NAV; routeHardened→H; groundSupport→G; escortedNow→E. Temporary protection affects physics but has no separate map badge. escort badge uses post-commit currentRound equality. Convoy signature changes produce a 1500ms visual pulse; evidence itself has no newly-arrived pulse.
