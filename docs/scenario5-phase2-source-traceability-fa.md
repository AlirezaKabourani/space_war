## محدودیت استنادی

هیچ منبعی در این فاز عددهای بازی یا loading شناختی را تأیید نمی‌کند. اصول reviewer-provided برای طراحی traceability استفاده شده‌اند، اما چون PDFها محلی نبودند، شماره صفحه، عبارت دقیق و ادعای «directly verified» برای آن‌ها ثبت نشده است. گزارش‌های محلی فقط synthesis ثانویه‌اند. پیش از استفاده پژوهشی/انتشار، PDFهای دقیق باید فراهم، صفحه‌ها دوباره بررسی و این ماتریس به نسخه citation-verified ارتقا یابد.
